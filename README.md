# 📱 Telegram Bot

Простой и удобный бот для Telegram, который просит пользователей подписаться на каналы перед доступом к контенту. Поддерживает несколько сценариев с разными наборами каналов и встроенную админ-панель прямо в боте.

## 🚀 Возможности

- ✅ **Сценарии** — создавайте разные наборы каналов под разные сценарии
- ✅ **Проверка подписки** — бот автоматически проверяет, подписан ли пользователь
- ✅ **Админ-панель** — управление сценариями и каналами прямо из чата бота
- ✅ **Рассылка** — отправляйте текст, фото и видео всем пользователям
- ✅ **Интерактивные кнопки** — удобное управление через inline-кнопки

## 📋 Требования

- **Node.js** v14+ 
- **npm** или **yarn**
- **Токен бота** от [BotFather](https://t.me/botfather)
- **Пароль админа** (на ваше усмотрение)

## 🔧 Установка

1. Клонируйте репозиторий (или скопируйте файлы):

```bash
git clone <repository-url>
cd notfunnydot
```

2. Установите зависимости:

```bash
npm install
```

3. Создайте файл `.env` (опционально) или используйте переменные окружения:

```bash
set BOT_TOKEN=your_bot_token_here
set ADMIN_PASS=your_admin_password_here
```

4. Запустите бота:

```bash
npm run start
```

## 📖 Использование

### Для обычных пользователей

Просто напишите команду `/start` и бот попросит вас подписаться на нужные каналы.

```
/start          - Начать
```

### Для администраторов

Сначала авторизуйтесь:

```
/admin YOUR_PASS
```

После этого станут доступны все админ-команды:

**Управление сценариями:**
```
/createscenario NAME              - Создать новый сценарий
/listscenarios                    - Посмотреть все сценарии
/removescenario NAME              - Удалить сценарий
/setscenario NAME                 - Установить глобальный сценарий
```

**Управление каналами:**
```
/addchannel SCENARIO link|title|content
  - Добавить канал в сценарий
  - Пример: /addchannel реклама https://t.me/mychannel|Подписаться|https://t.me/video
```

```
/listchannels SCENARIO            - Посмотреть каналы сценария
/removechannel SCENARIO INDEX     - Удалить канал по номеру
```

**Рассылка:**
```
/broadcast           - Начать режим рассылки
/sendbroadcast       - Разослать подготовленное сообщение
/cancelbroadcast     - Отменить рассылку
```

## 🎯 Примеры команд

### Создание сценария "Реклама"

```bash
/admin your_password
/createscenario Реклама
/addchannel Реклама https://t.me/channel1|Подписаться|https://t.me/video1
/addchannel Реклама https://t.me/channel2|Второй канал|https://t.me/video1
/setscenario Реклама
```

### Просмотр каналов в сценарии

```bash
/listchannels Реклама
```

### Удаление канала

```bash
/listchannels Реклама    # Посмотрите номер канала
/removechannel Реклама 1  # Удалите 1-й канал
```

### Отправка рассылки

```bash
/broadcast
# Отправьте текст, фото или видео
# После отправки сообщения:
/sendbroadcast          # Разошлет всем пользователям
```

## 🔐 Безопасность

- **ADMIN_PASS** хранится в переменных окружения (не в файлах)
- **BOT_TOKEN** также должен быть в переменных окружения
- Список админов хранится в `admins.json` (добавляется автоматически после /admin)
- Всегда используйте сложный пароль для админ-панели

## 📝 Файлы данных

| Файл | Описание |
|------|---------|
| `scenarios.json` | Все сценарии с привязанными каналами |
| `users.json` | ID пользователей и их выбранные сценарии |
| `admins.json` | ID авторизованных админов |
| `settings.json` | Глобальный активный сценарий |
| `pendingBroadcasts.json` | Очередь сообщений для рассылки |

## 🤝 Поддержка

Если что-то не работает:

1. Проверьте, что бот добавлен в каналы и имеет права на проверку участников
2. Убедитесь, что переменные окружения установлены правильно
3. Посмотрите логи запуска бота в консоли
